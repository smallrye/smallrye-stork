= SmallRye Stork documentation

The documentation is AsciiDoc, laid out like the Quarkus guides, and published on
https://smallrye.io/docs/smallrye-stork/latest/[smallrye.io]. The site pulls it from this
repository: the `main` branch every night, and each release once it is tagged.

== Where things are

[cols="1,2"]
|===
|`src/main/asciidoc/**/*.adoc` |One page per file. The path is the page's address: `load-balancer/random.adoc` is published at `/docs/smallrye-stork/<version>/load-balancer/random/`.
|`src/main/asciidoc/_nav.yml` |The sidebar: page order and sections. A new page must be added here.
|`src/main/asciidoc/_attributes.adoc` |Attributes every page includes (ids, `examples-dir`, `project-version`, ...).
|`src/main/asciidoc/images/` |Images, referenced as `image::images/name.png[]`.
|`src/main/java/` |Code examples. They compile with the build, so they cannot go stale.
|===

The attribute tables of the service discovery, load balancer and service registration providers are
generated by `stork-configuration-generator` (`META-INF/stork-docs/*-attributes.adoc` in each
provider jar). The docs module unpacks them to `target/attributes`, and pages include them with
`include::{generated-dir}/random-lb-attributes.adoc[]`.

== Writing a page

[source,asciidoc]
------
= Page title
include::_attributes.adoc[]
:summary: One sentence for search engines and the page description.

Text...

== A section

Link to another page with xref:service-discovery/dns.adoc[DNS], or to a section of it with
xref:service-discovery/kubernetes.adoc#caching-the-service-instances[].

[source,java]
----
include::{examples-dir}/examples/AcmeLoadBalancer.java[]
----
------

* A page in a subdirectory starts with `:version-root: ../` (one `../` per level) and includes
  `{version-root}_attributes.adoc`.
* Section ids are Quarkus-style: `== Caching the service instances` gets the id `caching-the-service-instances`.
* Include part of an example by marking it with `// tag::example[]` and `// end::example[]`.
* Admonitions: `NOTE:`, `TIP:`, `IMPORTANT:`, `WARNING:`, `CAUTION:`.
* Diagrams are PlantUML blocks (`[plantuml,name,svg]`); smallrye.io renders them.

== Previewing

Pull requests that change the documentation are rendered with the smallrye.io site by the
`Documentation` workflow, which fails on a broken include or a page that does not render. The
rendered site is attached to the workflow run as the `docs-smallrye-stork` artifact.

To see the documentation the way smallrye.io shows it while you write it, run from this repository:

[source,bash]
----
./mvnw -Pdocs-preview
----

and open http://localhost:8080/docs/smallrye-stork/main/. Pages and included examples are published again
when you save them; refresh the page. Only Java is needed: the profile runs the
https://github.com/smallrye/smallrye.github.io/tree/develop/tools/docs[smallrye.io docs tools]
with https://www.jbang.dev[JBang]. Where JBang is installed, `jbang docs-preview@smallrye/smallrye.github.io`
does the same, and takes options such as `--port` or `--site <a smallrye.github.io checkout>`
(see `--help`).
